# 핏스닥 FITSDAQ — 내 체력이 상장되는 거래소

국민체육진흥공단이 공공데이터포털에 공개한 **국민체력100 합성데이터**로 개인의 체력을 '주식 시세'처럼 보여주는 웹 서비스입니다.

- 내 종목 상장: 성별·연령 업종 안에서 체력 시세(현재가), 업종 순위, 체력나이, 신용등급
- 생애 근력 차트: 악력 백분위 기준 10~90세 캔들 차트와 근감소증 경고선(AWGS 2019) 도달 나이
- 애널리스트 리포트: 투자의견, 12주 목표주가, 추천 운동 포트폴리오
- 핏스피(FITSPI): 체력측정 참여 15만 건으로 만든 국민 체력측정 참여지수
- 종목 시세판: 스포츠강좌이용권·장애인스포츠강좌이용권 종목별 수강료와 거래량

정적 웹(HTML/CSS/JS, 외부 라이브러리 없음). 모든 계산은 브라우저에서 이뤄지며 입력값은 서버로 전송되지 않습니다. PWA(설치·오프라인) 지원.
