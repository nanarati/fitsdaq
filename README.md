# 핏스닥 FITSDAQ — Fitness Navigation

국민체육진흥공단이 공공데이터포털에 공개한 **국민체력100 합성데이터**를 바탕으로 개인의 체력을 하나의 가격이 아니라 **현재 위치와 개선 방향**으로 보여주는 웹 서비스입니다.

- 체력 나침반: 근력·심폐지구력·체성분·혈압을 여러 축으로 표시
- 종합 체력지수: 같은 연령·성별 비교군과의 위치를 100점 기준으로 요약
- 체력나이: VO₂max(65세 이상은 8자보행)와 근력 위치를 이용한 참고 지표
- 생애 근력 궤적: 현재 경로, 꾸준한 운동, 활동 감소 시나리오와 AWGS 2019 주의선
- 12주 개선 시나리오: 가장 약한 영역을 중심으로 한 가상 체력지수 변화
- 추천 운동 조합: 스포츠강좌이용권 이용실적(합성)을 참고한 운동 구성
- FITSPI: 국민체력100 체력측정 참여 흐름을 보여주는 참고 지수

## 활용 데이터

| 데이터 | 규모 |
|---|---:|
| 국민체력100 간소화 체력측정 결과(합성) | 20,000건 |
| 국민체력100 체력측정 참여 현황(합성) | 150,000건 |
| 스포츠강좌이용권 이용실적(합성) | 50,000건 |
| 장애인스포츠강좌이용권 이용실적(합성) | 50,000건 |

`data/` 폴더에는 원천 데이터를 요약한 분위수 표·표본·참여지수가 들어 있습니다.

## 구조

정적 웹(HTML/CSS/JS, 외부 차트 라이브러리 없음)이며 모든 계산은 브라우저에서 수행됩니다. 입력값은 서버로 전송되지 않습니다. PWA 설치·오프라인 사용을 지원합니다.

본 서비스는 의료 진단 서비스가 아니며, 생애 궤적과 12주 예상값은 실제 미래 상태를 보장하지 않는 시나리오입니다. 국민체육진흥공단의 공식 서비스가 아닙니다.
